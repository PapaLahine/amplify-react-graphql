# User stories – MVP sécurité

## Agent de sécurité

1. En tant qu’agent, je veux démarrer ma ronde depuis mobile afin de tracer mon heure de début.
2. En tant qu’agent, je veux pointer un checkpoint via QR/NFC afin de prouver mon passage.
3. En tant qu’agent, je veux signaler un incident avec photo et gravité afin d’alerter rapidement.
4. En tant qu’agent, je veux voir la liste de mes rondes du jour afin de m’organiser.

## Superviseur

1. En tant que superviseur, je veux planifier les rondes par site afin d’assurer la couverture.
2. En tant que superviseur, je veux recevoir des alertes en cas de checkpoint manqué afin de réagir.
3. En tant que superviseur, je veux assigner et suivre les incidents afin de respecter les SLA.
4. En tant que superviseur, je veux suivre les agents actifs sur carte/tableau afin de coordonner.

## Direction

1. En tant que direction, je veux un dashboard global multi-sites afin de suivre la performance.
2. En tant que direction, je veux voir les tendances incidents (fréquence, gravité, site) afin de décider.
3. En tant que direction, je veux accéder aux rapports de conformité des rondes afin d’auditer l’exploitation.

## Admin système

1. En tant qu’admin, je veux gérer les rôles et permissions afin de sécuriser l’accès.
2. En tant qu’admin, je veux configurer les seuils d’alerte et canaux de notification.
3. En tant qu’admin, je veux consulter le journal d’audit afin de tracer les changements.
